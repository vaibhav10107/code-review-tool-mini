# code-review-tool-mini

A simple Python library to annotate and review code snippets.

> This tool can help developers quickly review and annotate code snippets, improving code quality and collaboration.

## Features

- Contains the main functions for annotating and reviewing code
- Tests the core functionality of the code review tool
- Verified by tests: pytest will verify that the functions correctly annotate and review code snippets.

## Requirements

- Python 3.11+
- Stack: python, pytest

## Install

```bash
git clone <this-repo>
cd code-review-tool-mini
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python -m pytest
```

Example output:

```text
>>> review_code('def add(a, b):\n    return a + b\n')
'def add(a, b):\n    return a + b\n# Code is correct!'
```

## Tests

```bash
pip install pytest
python -m pytest -q
```
